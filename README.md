# Eagle Plugin Mini Map

A plugin to visualize image locations on a map in Eagle App.

<img width="374" height="412" alt="Image" src="https://github.com/user-attachments/assets/9786bfd2-66d2-482a-9b9a-7be5bb7b5f1c" />

## Usage

```
pnpm ci
pnpm run build
```

- Import the `dist` folder as a plugin in Eagle App.

## How to Debug Plugins

You can right-click on the inspector plugin in the screen and then select "Developer Tools" to start debugging.
